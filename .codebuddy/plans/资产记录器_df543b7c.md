## 产品概述

在现有 QQSG 工具箱「记录器」分组下新增一个**资产记录器**，用于记录玩家购入的装备及其价格，并以趋势图直观展示每件装备的价格走势与总体资产走势。数据按当前账户隔离存储，风格与现有记录器（羽灵 / 八阵图 / 投城）保持一致。

## 核心功能

- **装备管理**：新增 / 编辑 / 删除装备，每件装备包含名称、备注等基础信息。
- **双模式价格录入**：每条价格记录可任选一种方式录入
- a) 三国币数量 + 币价（元/亿三国币）
- b) 直接输入人民币（RMB）
为保证两种口径可互算，方式 b 录入时同样需提供当时币价（可自动预填最近一次币价）。
- **多次估值快照**：每件装备除购入价外，可按不同日期多次追加估值记录，形成随时间变化的价格走势。
- **趋势图**：
- 每件装备一条价格走势曲线；
- 一条**总体资产走势**曲线（某时间点总资产 = 各装备在该时刻最近一次有效估值之和）；
- 支持在 **RMB / 三国币** 两种口径之间切换查看（两者都可显示）。
- **总览统计**：展示装备数量、当前总资产（RMB 与 三国币双口径）等汇总信息。
- **账户隔离**：切换账户自动重载对应数据；删除账户时同步清理该账户的资产数据。

## 换算规则

- RMB = 三国币数量 ÷ 1e8 × 币价（元/亿）
- 三国币数量 = RMB ÷ 币价 × 1e8

## 技术栈

- 沿用现有前端栈：**Wails + Vue 3 + TypeScript + Vite**，UI 组件库 **animal-island-vue**（Card / Modal / Button / Input）+ 自定义组件 `@/components/Field.vue`、`@/components/NumberInput.vue`。
- 图表：**纯 SVG 手绘折线图**（参考 `YulinExpChart.vue`），无第三方图表库依赖。
- 持久化：复用 `@/logic/kvStore` 的 `storage` + `@/logic/account` 的 `scopedKey`，按当前账户分桶存储。

## 实现方案

采用与现有记录器完全一致的「**logic 数据层 + Record 视图 + SVG 图表组件 + 路由/菜单/清理注册**」四段式结构，最大化复用现有模式，降低维护成本与认知负担。

### 数据模型（frontend/src/logic/asset.ts）

- `PriceMode = 'coin' | 'rmb'`
- `PriceEntry`：一条价格记录（购入价或估值快照）
- `id`、`date`(YYYY-MM-DD)、`mode`、`coinAmount`(三国币数量)、`coinPrice`(币价 元/亿)、`rmb`、`note?`
- 两种口径均可推导（方式 coin 由 coinAmount+coinPrice 推 rmb；方式 rmb 由 rmb+coinPrice 反推 coinAmount）。
- `AssetRecord`：一件装备
- `id`、`name`、`note?`、`createdAt`、`entries: PriceEntry[]`（按日期升序，首条视为购入价）。
- `Store = { records: AssetRecord[], lastCoinPrice?: number }`

### 计算与聚合

- `entryRmb(e)` / `entryCoin(e)`：单条记录双口径换算。
- `latestEntryOnOrBefore(record, date)`：某装备在指定时间点前最近一次有效估值。
- `buildTrendSeries(records, unit)`：收集所有记录中出现过的**去重日期**并升序排列作为统一 X 轴；对每个日期计算各装备最近估值（阶梯保持，前向填充）与总资产，产出「每装备一条系列 + 总体一条系列」。复杂度 O(D×A)（D=日期数，A=装备数），数据量小，性能无瓶颈；用 `computed` 缓存避免重复计算。
- 工具函数：`genId()`、`todayStr()`、`fmtInt()`、`fmtDec()`、`fmtBig()`、`fmtRmb()`、`fmtCoin()`（对齐 city.ts 风格）。
- `normalizeRecord()`：兼容/修补旧数据字段；`loadStore()/saveStore()/clearAccountData()` 与 city.ts 保持同构。

### 关键决策与权衡

- **双口径统一存储**：每条记录同时持有 `coinPrice`，使 RMB 与三国币可随时互算，避免因单位选择导致某一口径缺失。方式 b 录入时默认预填 `lastCoinPrice`，用户可修改。
- **趋势图前向填充**：总资产按「各装备最近一次估值之和」聚合，符合"资产快照"语义，避免未估值时段被当作 0。
- **RMB 与三国币不同量级**：两口径共用一个 Y 轴会失真，因此图表提供**单位切换按钮**（RMB / 三国币），一次展示一种口径的全部曲线；总览统计卡片同时显示两种口径数值，满足"两者都显示"。
- **多系列 SVG**：在 `YulinExpChart.vue` 单折线基础上扩展为多 `polyline`，装备曲线细线 + 总体曲线加粗高亮，配色取自现有暖色 token。

## 实现注意事项

- 数据按账户隔离：视图内 `reloadFromStore()` + `watch(activeAccountId, ...)`，切账户时重载数据并关闭弹窗/清空展开态（对齐 RecordCity.vue）。
- 存储 key 采用 `qqsg.record.asset.v1`，经 `scopedKey` 命名空间化。
- 表单校验：装备名必填；价格记录按 mode 校验对应字段（coin 模式校验 coinAmount>0 且 coinPrice>0；rmb 模式校验 rmb>0 且 coinPrice>0）。
- 复用现有暖色风格与 scoped 样式约定，包含 `@media` 响应式；不引入新全局样式。
- 保持向后兼容，不改动其它记录器逻辑；集成注册点为最小侵入式追加。

## 关键数据结构

```typescript
export type PriceMode = 'coin' | 'rmb'

export interface PriceEntry {
  id: string
  date: string          // YYYY-MM-DD
  mode: PriceMode
  coinAmount: number    // 三国币数量（coin 模式录入）
  coinPrice: number     // 币价：元 / 亿三国币（两种模式都需要）
  rmb: number           // 人民币（rmb 模式录入）
  note?: string
}

export interface AssetRecord {
  id: string
  name: string
  note?: string
  createdAt: number
  entries: PriceEntry[] // 按 date 升序，[0] 为购入价
}
```

## 设计风格

延续项目「动物森友会」暖色手绘风格，与羽灵 / 投城记录器视觉完全统一，使用 animal-island-vue 组件（Card / Modal / Button / Input）搭配自定义 Field / NumberInput。整体温馨圆润、卡片化布局、虚线描边、圆角与轻投影。

## 页面结构（单页 RecordAsset）

- **顶部标题 Card**：`type="title" color="app-yellow"`，标题「资产 · 装备价格记录」。
- **总览统计块（stats-grid）**：装备数量、当前总资产(RMB)、当前总资产(三国币)、最近币价等统计卡，双口径并列展示。
- **趋势图 Card**：右上角单位切换（RMB / 三国币 分段按钮）；下方为 `AssetTrendChart` 多系列曲线，含图例（各装备 + 总体资产加粗高亮）、hover tooltip 显示该点日期与数值。
- **装备列表 Card**：可展开/折叠的装备卡片（rec-card 风格），折叠态一行预览（名称/购入价/当前估值/涨跌）；展开态显示该装备的估值明细表（日期、录入方式、三国币、币价、RMB）与「＋ 追加估值」按钮。顶部提供「＋ 添加装备」。
- **添加/编辑 Modal**：装备名 + 备注；价格记录列表，每条含日期、模式切换（三国币+币价 / RMB）、对应输入框，实时显示双口径换算结果。
- **删除确认 Modal**：与现有一致的警示样式。

## 交互与动效

- 卡片 hover 轻微上浮/描边高亮；展开折叠平滑过渡；曲线数据点 hover 放大并显示竖向参考线与 tooltip；单位切换即时重算曲线。
- 响应式：`@media (max-width: 900px)` 下统计网格与表单栅格降列，图表自适应宽度。
