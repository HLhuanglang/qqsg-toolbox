# 2026-07-13

## 资产记录器（新增功能）
为 QQSG 工具箱「记录器」分组新增"资产记录器"，用于记录购入装备价格与走势。

### 需求确认
- 走势模型：多次估值快照（每件装备有购入价 + 多个日期估值）
- 币价单位：元 / 亿三国币（RMB = 三国币数量 / 1e8 × 币价）
- 价格双模式录入：a) 三国币数量+币价；b) 直接 RMB（同时记录当时币价以互算）
- 总体资产走势：RMB 与 三国币两种口径都显示（图表单位切换 + 总览双口径卡片）

### 交付文件
- `frontend/src/logic/asset.ts`（新）：类型 PriceEntry/AssetRecord/Store、双口径换算 entryRmb/entryCoin、趋势聚合 buildTrendSeries（前向填充/阶梯保持）、assetTotals、持久化 loadStore/saveStore/clearAccountData、工具函数。STORE_KEY = `qqsg.record.asset.v1`。
- `frontend/src/components/AssetTrendChart.vue`（新）：多系列纯 SVG 折线图，每装备一条线 + 总体资产加粗线，图例可点击隐藏，透明列命中区触发 HTML 悬浮 tooltip，unit(rmb/coin) prop 切换。
- `frontend/src/views/RecordAsset.vue`（新）：总览统计 + 趋势图(单位分段切换) + 可展开装备列表 + 添加/编辑 Modal(装备名+多条价格记录, 每条 coin/rmb 模式切换+实时换算) + 删除确认 Modal。按账户隔离。
- 集成：`router/index.ts` 加 `/record/asset`；`App.vue` record 菜单加「资产」；`Profile.vue` 账户删除 onCleanup 加 clearAssetData。

### 校验
`cd frontend && npx vue-tsc --noEmit` 通过，无 lint 错误。
